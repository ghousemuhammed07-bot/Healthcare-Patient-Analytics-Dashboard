**Healthcare Patient Analytics Dashboard**
Project Overview
This project focuses on analyzing healthcare patient data using Power BI. The dashboard provides insights into patient demographics, treatment costs, hospital performance, patient outcomes, and satisfaction scores.

**Tools Used**
Power BI
Power Query
DAX

**Dataset Features**
Patient Demographics
Admission & Discharge Information
Treatment Costs
Insurance Details
Patient Outcomes
Satisfaction Scores
Readmission Analysis

**Dashboard Pages**
1. Executive Overview
Total Patients
Total Revenue
Average Treatment Cost
Average Length of Stay
Average Satisfaction Score

2. Patient Analysis
Age Group Distribution
Gender Distribution
Diagnosis Analysis
Insurance Distribution
Satisfaction Analysis

3. Financial Analysis
Revenue by Department
Revenue by Diagnosis
Revenue by Insurance Type
Cost Category Analysis
Monthly Revenue Trends

4. Clinical Performance
Outcome Analysis
Department Performance
Length of Stay Analysis
Satisfaction Analysis

**Insights**
Patient distribution across departments and regions
Revenue drivers by diagnosis and department
Treatment cost patterns
Clinical outcome performance
Patient satisfaction trends
